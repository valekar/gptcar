# Full reconstruction run

The user rejected the initial51 abbreviated studies because their scripts and artwork departed too far from the original films. Those studies remain historical first-pass work. They are not accepted reconstructions.

All51 published originals now have complete scene/script briefs in [the reconstruction index](matched-briefs/README.md). The team inspected complete-film reference sheets, source timing/word tables and additional exact frames at short shots, gestures and transitions. This is scene coverage, not a claim that a person inspected every encoded frame.

The new run preserves each original title/topic, narrative, exact narration text, on-screen copy, scene sequence and actual published delivery format. Voice, music and foley are freshly performed/generated. New scene code may use credited generic style engines and original licensed data. Original scene replay and original movie frames are not classified as new GPT artwork. The original private conversation prompts were not published.

Current accepted reconstructions: Swiss Motion Graphics, Glass Product Render, Watercolor Brush Brick Toy and Crayon Picture Book. Further styles are being rendered/reviewed; remaining styles are in production. No final Pages deployment has been made.

Each accepted film has a source-bound record in `replica-reviews/`, a technical render record in `replica-results/`, and a prompt/treatment/credits bundle in `../replicas/`. Acceptance checks full scene fidelity, narration/timing and audio, delivery frame count, resolution/fps, media hashes, and deterministic seeking. Remaining small visual differences are disclosed beside each pair; acceptance does not mean pixel identity.

The one-page gallery is published only when all51 current films have passed. The strict builder rejects abbreviated, stale, unreviewed or wrong-model artifacts. Release media and matched-time preview images carry independent SHA-256 checks. The rejected first-pass release stays a separate draft.
