# Teardown reference recreation guidance

For a matched recreation, pin every engineering file to the original revision. Restore the same case/plate/PCB data before rendering. Check case bounding dimensions and the four-hole transform against the PCB/plate, rather than assuming that files from the same repository fit. Preserve all switch positions, package footprints and both sides of the routed board.

Use the correct non-panel outline. A KiCad board may include manufacturing tabs; the matching plate outline inset by the measured clearance can define the intended half. Generic lofted-part, layout-map and package geometry helpers may be reused with attribution, while the complete assembly, camera, story and scene-specific overlay application remain newly authored. State the reuse precisely and never run the original main scene as the replica.

Store the measured camera and timeline as reference data. Apply monotone eye/target tracks so the camera holds the macro without overshoot. Preserve the top-first opening, corner-distance cap wave, extra PCB-to-case gap, second switch gap, macro stops, bottom-first closing and individual cap stroke/landing response. Sample the short press and key landings between ordinary review frames.

Board macro detail is part of the subject. Paint copper pours, traces, vias, pads, drills and silkscreen from the actual extracted layout, and place plain package bodies at their real footprints. Keep source dimensions on anchored leaders and perspective lines. Generic package heights and aesthetic materials should not acquire new factual labels.

Recreate all original words with fresh voice, retaining the spoken RP2040 pronunciation. Build a new score with the same tempo and sectional palette, both near-silences and individual material cues. Derive one lift and one landing cue for each actual key from its animation rank, and place dimension sounds on the actual drawing times. Review the complete thirteen-part sequence and the final five-second title.
