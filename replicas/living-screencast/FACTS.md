# Reference scope

This is an unofficial historical reference recreation of the original published Claude Code/app walkthrough. Exact app labels, shortcuts, model badge and demo tomato-timer code are preserved from that film. This does not certify the current product interface or make new claims about current features. The timer project and test outputs are coherent demonstration content. Shared ui.js includes the exact theme.ts diff fixture; this reuse is disclosed in CREDITS and generation.json. All narrative assembly and motion tracks are new.
